# Archive

This folder holds files kept for reference but moved out of the publish-facing
project root:

- `bin/`: duplicate, original, temporary, and test binaries.
- `build-output/`: assembler listings and labels.
- `config/`: older One ROM config experiments.
- `upstream/`: original PETTESTE2K reference files and manuals.
- `vice/`: local VICE ROM set and launcher helpers.
